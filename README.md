## Read Me

This is the repository for my portfolio website. To run locally, [install Ruby](https://www.ruby-lang.org/en/documentation/installation/), clone the repository, and from the repo directory run:

```
gem install bundler jekyll jekyll-feed
bundle exec jekyll serve
```
