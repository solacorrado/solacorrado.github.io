### Project Description
Developing an intuition about the structure of the brain is difficult. We can examine the brain through discrete slices, but we rarely get to visually move through the brain in 3D. This project aimed to utilize large, multi-touch-enabled display screens to create a game to practice and test neuroanatomy skills using real MRI images. Users are presented with a whole-brain set of MRI images sourced from the Duke Institute for Brain Sciences, and they can scroll through these images to create the illusion of moving through the brain. The game involves finding the best slice to identify a brain structure or region, tapping the location of the structure, and learning about the anatomy, function, and pathologies associated with it. Features such as time limits and points are incorporated to gamify the experience, and the multi-touch feature encourages collaboration while learning and testing. Immediate feedback is provided through incorrect answer detection and highlighting the right answer. 

### My Contributions
- Designed and tested prototypes of neuroanatomy games in Processing using AI-assisted coding to clarify the capabilities of the multiuser touch screen and variations of studying neuroanatomy, including an MRI brain slice ordering game
- Drove UX/UI design to incorporate easy navigation, gamification features, and separate learning and testing modes to increase user engagement and facilitate hands-on learning and teamwork
- Wrote educational blurbs on anatomical, functional, and pathological information about each brain region to make the game an interactive and informative learning platform

### Future Directions
A limitation of this game is that the MRI images and brain regions are hard coded into the program. Making this game compatible with any MRI image set would increase the versatility and use of the game across institutions and platforms. New features can also include starring previously incorrect questions to review them more intentionally and a free-response question to move through the image slides and identify all structures without prompting.
